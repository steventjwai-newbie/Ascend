# Security and privacy

This public repository contains a deliberately redacted judging artifact.

It must not contain:

- credentials, access tokens or environment files;
- production API endpoints or database identifiers;
- private invoices, receipt images or customer information;
- production supplier names, invoice numbers or source row IDs;
- write-capable connections to operational systems.

The dashboard is read-only and uses static anonymized snapshots. Consequential production actions remain behind separate authenticated systems and explicit human approval.

If you discover private information in this repository, do not open a public issue. Contact the repository owner privately through their GitHub profile.
